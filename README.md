# Personal-finance-calculator
Aplicação desenvolvida em Python para gerenciamento e análise de finanças pessoais. Permite registrar receitas e despesas, calcular a distribuição percentual dos gastos por categoria e monitorar o saldo disponível, utilizando estruturas condicionais, laços de repetição e recursos da linguagem.

Funcionalidades
- Registro de salário e despesas.
- Cálculo automático dos gastos.
- Análise percentual por categoria.
- Acompanhamento do saldo restante.
  
Tecnologias utilizadas
- Python 3
- Estruturas condicionais (if, elif, else)
- Laços de repetição (while)
- Operações matemáticas
  
Objetivo:Projeto desenvolvido para praticar lógica de programação e aprimorar conhecimentos na linguagem Python.
